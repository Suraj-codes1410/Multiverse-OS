# Desktop Directory

This directory houses high-density, complex, desktop-optimized dashboards, overlays, and explorers.

## Usage Guidelines
* Use this folder for components that represent complex feature workflows (e.g. `RecruiterDashboard`, `SkillsDashboard`, `GithubExplorer`, `KnowledgeExplorerClient`, `CliTerminal`, `OracleWindow`, `GithubRepoDetail`).
* These components typically handle local component state, paste events, pathfinding algorithms, and async API communications.
